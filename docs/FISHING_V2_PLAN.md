# 钓鱼系统 2.0：调研与设计方案（2026-11-05，设计稿，还没写代码）

> 目标：鱼类图鉴升级（含**鱼竿图鉴 / 饵料图鉴**）、新鱼竿（含特殊鱼竿）、新饵料、一档**更高级别的鱼**、**钓到盲盒**（特殊物品 + 特殊鱼类），并参考《星露谷物语》的钓鱼模式看还有什么值得加。
> 本文只借鉴**玩法思路**；名称、数值、美术全部原创（项目美术都是程序化生成），不使用星露谷的任何素材或名字。末尾「需要你拍板的事」定下来后再开工。

## 1. 我们现在有什么（做方案前盘点）

| 模块 | 现状 |
|---|---|
| **鱼** | 25 种真鱼 + 4 种杂物，分 常见 / 少见 / 稀有 / 史诗 / 传说 五档（`src/shared/fishing.ts`）；出现概率受**昼夜、下雨、季节**影响；有尺寸、重量、「迷你 … 巨物」个头档位；传说 3 条（黄金锦鲤、冰湖银鱼王、精工湖神龙）。 |
| **鱼竿** | 3 根：竹节（每天登录送）、碳素（420 币）、金龙（1800 币）；每根有 `ease`（拉鱼难度）、`wait`（咬钩时间）、`luck`（稀有鱼倍率）三个数。**背包里的「钓鱼装备栏」**可以选用哪根竿、哪种饵（默认用最低级的）。 |
| **饵** | 2 种：鱼饵（10 币 ×5，每天送）、香饵（30 币 ×5，咬钩快 25%、稀有 ×1.25）。 |
| **拉鱼小游戏** | 右侧水柱 + 绿条（`FightSim`）：鱼有三种游法（smooth / mixed / dart），难度 = 稀有度基础 + 个头 − 鱼竿 `ease`；「完美」（鱼几乎一直在绿条里）会让尺寸向上限靠近 30%。服务器只校验时间，不重放。 |
| **图鉴** | 「图鉴」里已经有**钓鱼图鉴**一页：25 种鱼按稀有度分组，没钓到的显示剪影；记录每种钓到几条、最大尺寸、最重一条（`Saved.fd`）。集齐 = 成就「钓鱼大师」+ 称号。**没有**鱼竿 / 饵料的图鉴。 |
| **周边** | 每日任务「湖边垂钓」、5 个钓鱼成就和称号、卖鱼（今日行情）、喂猫（鱼的稀有度换好感）、名人堂钓鱼榜、翻垃圾桶（另一条"捡东西"线）。 |
| **经济** | 抛一次竿期望收入约 12.7 币；钓鱼是币的主要来源，鱼竿是主要的币的出口（见 [ECONOMY.md](ECONOMY.md)）。 |

**所以"新增鱼类图鉴"实际是升级**：把现有的钓鱼图鉴扩成三栏——**鱼类 / 鱼竿 / 饵料（含配件）**，鱼竿和饵料的图鉴在鱼类下面。

## 2. 星露谷钓鱼调研（只记对我们有用的）

| 星露谷的机制 | 它是怎么做的 | 我们现在 | 值不值得加 |
|---|---|---|---|
| **鱼竿分档 + 装配件的槽** | 竹竿 / 训练竿不能挂饵，之后的玻璃纤维竿、铱竿、高级铱竿依次增加饵和**配件**槽。 | 3 档竿，没有槽，饵由装备栏选 | ✅ 给高档竿加「配件槽」，是新鱼竿最大的玩点 |
| **饵的种类** | 普通饵缩短咬钩时间；**野饵**有机会一次钓双份；**魔法饵**无视季节和天气；**磁铁饵**提高宝箱概率；**豪华饵**让绿条更长；（1.6 还有按鱼种定向的"指名饵"，我印象里是这样，没核实）。 | 2 种饵 | ✅ 饵是最便宜的内容扩展：每种饵一个特效 |
| **配件（Tackle）** | 约 10 种：旋转饵 / 加料旋转饵（咬钩更快）、**陷阱浮标**（鱼溜得慢）、**软木浮标**（绿条变长）、**铅坠浮标**（绿条下沉更稳）、**倒刺钩**（绿条会"黏"住鱼，适合慢游的常见鱼）、**好奇诱饵**（稀有 / 传说更容易）、**品质浮标**（提高鱼的品质）、**声呐浮标**（咬钩前就显示是什么鱼）、**寻宝者**（更容易出宝箱、拉宝箱时鱼不会跑）。 | 没有 | ✅ 这些几乎都能直接映射到我们的 `FightSim` 参数（绿条长度、下沉、掉进度速度）和 `rollFish` 权重，实现成本低 |
| **品质星级** | 「完美」捕获（鱼一直没离开绿条）→ 更高品质（银 / 金 / 铱星），卖价更高、经验更多。 | 完美 → 尺寸 +30% | ⚠️ 要不要做星级见 §5.3（会动背包数据结构） |
| **拉鱼时的宝箱** | 小游戏里偶尔出现一个宝箱图标，要让绿条同时"罩住"宝箱把它的进度条拉满，拉完鱼才拿到；**鱼跑了宝箱也没了**；有金宝箱（精通后）；节日钓鱼不出宝箱。奖励随运气和钓鱼等级而变。 | 没有 | ✅ 正好对应你要的**盲盒**（两种做法见 §6） |
| **传说鱼** | 一共 5 条（另有二代 5 条），**每个存档只能钓一次**，在小游戏里**头顶有橙色皇冠**，有地点 / 季节 / 天气 / 等级要求，要配套的饵和竿。 | 3 条传说，靠运气 | ✅ 我们的"更高级别鱼"可以学：**有条件才出现**，而不是单纯更低概率 |
| **钓鱼技能与职业** | 钓鱼有经验和 10 个等级：等级解锁配件 / 蟹笼 / 绿条加长；5 级选「渔夫（鱼价 +25%）」或「捕手」，10 级选「钓手（鱼价 +50%）」「海盗（宝箱概率翻倍）」或蟹笼相关。 | 没有等级，只有成就 | ✅ **钓鱼等级**是很好的长线进度，且能做解锁门槛（P3） |
| **蟹笼** | 放在水边，需要饵，下次来收；有自己的一套"笼里"的产物（龙虾、蛤蜊等）；职业可以去掉杂物 / 免饵。 | 没有 | ⚠️ 被动收益，和我们的每日循环搭，但会让币通胀、服务器要记计时（P3 再议） |
| **鱼塘** | 一个塘养一种鱼，初始容量 3、做"种群任务"升到 10；鱼会繁殖、产鱼籽等产物。 | 没有 | ⚠️ 对应我们的**宿舍鱼缸**（展示 / 轻量产出），见 §7，P3 |
| **其他**（凭印象，未核实） | 水族馆 / 鱼缸装饰、威利的渔具店、钓鱼节日比赛、地点各自的鱼池（河、湖、海、洞穴）、每日运气影响。 | 钓鱼榜、行情 | 钓具店 / 比赛 / 钓点见 §7 |

调研来源见文末。星露谷里的数值各来源不太一致（比如陷阱浮标减慢多少、好奇诱饵的倍率），**我们不照抄数值，只借思路**，数值按我们自己的经济重新定。

## 3. 总体设计思路

1. **数据驱动**：鱼、竿、饵、配件、盲盒都是 `src/shared/` 里的一张表（服务端和客户端共用），加一行 + 一个图标就能上线；`tests/` 检查"目录、物品、图标三者一致"（沿用现在的做法）。
2. **服务器权威**：抛竿 / 咬钩 / 抽鱼 / 开盲盒的随机全在服务器；客户端只显示与上报（和现在一样）。装备是否合法、背包里有没有这件东西，服务器校验。
3. **"差异化"而不是"数值膨胀"**：新鱼竿和新饵不是"更大的数"，而是**各有一个特长**（夜里、雨天、冬天、宝箱、双份……），玩家按场合换装，这样装备栏才有意义。
4. **图鉴是主线**：每件东西第一次获得 / 使用就解锁图鉴，图鉴里写"怎么得到"的提示，集齐有奖励；这让新东西既是玩法又是收集目标。
5. **不破坏经济**：最高档装备让每杆收入提高约 20~30%，同时增加币的出口（贵的竿、配件、合成），不让币通胀（见 §8）。

## 4. 新鱼类：一档更高级别的鱼

### 4.1 新稀有度「神话」（`mythic`）
在传说之上加一档 **神话**（颜色建议深红 / 紫金渐变，图鉴里带光效）：
- 拉鱼难度基础 0.70（传说 0.56），游法更凶（`dart` + 中途会"发力"一次）；
- 基础卖价 1400（传说 420）；喂猫好感 +50（传说 +30）；
- **不是单纯低概率，而是有条件才出现**（学星露谷的传说鱼）：要同时满足 ① 用指定的饵（「神话饵」，只能合成 / 盲盒得到）② 指定的竿（金龙竿及以上，或对应的特殊竿）③ 指定的环境（比如"冬天 + 夜里 + 雨雪"）；每个神话鱼的条件不同，图鉴里解锁后才写出来；
- 拉鱼时鱼图标头顶有**橙色（或红色）皇冠**，让玩家知道"这条不一般"；
- 钓到时**全服公告一句**（"某某钓到了神话鱼「xxx」！"），写进名人堂；**每个玩家每种神话鱼首次钓到有一次性大奖**（称号 + 币 + 专属物品），之后再钓照常卖钱。

### 4.2 神话鱼候选（先给 3 条，用你的反馈选）
| 候选 | 点子 | 条件 | 备注 |
|---|---|---|---|
| **「镇湖玄龟」** | 驮着碑文的老龟，慢得像山 | 冬天 + 夜里，要「寒江竿」或金龙竿 | 游法 smooth 但**绿条极短**，考耐心 |
| **「应龙」** | 传说里的有翼之龙，只在暴雨夜出水 | 下雨 + 夜里，要「听雨竿」 | `dart` 最凶，进度掉得快 |
| **「河工锦」**（校园彩蛋） | 一条身上有校徽花纹的锦鲤，和"河北工程大学"绑定 | 春季白天 + 钓满 20 条锦鲤后解锁（"锦鲤的回礼"） | 最容易，当第一条神话鱼，给大家一个目标 |

另外建议加 **5 条盲盒限定鱼**（§6.3）和几种新的杂物 / 宝物。每条新鱼 = 一行数据 + 一个像素图标（`tools/art/items.ts` 程序化画）+ 一段图鉴描述。

| 竿 | 档位 | 基础 `ease / wait / luck` | 配件槽 | 特长（perk） | 获得方式 |
|---|---|---|---|---|---|
| 竹节竿（现有） | 入门 | 0 / 1 / 1 | 0 | — | 每天登录送、商店 40 |
| 碳素竿（现有） | 进阶 | 0.1 / 0.8 / 1.25 | 1 | — | 商店 420 |
| 金龙竿（现有） | 高级 | 0.2 / 0.62 / 1.6 | 1 | — | 商店 1800 |
| **萤火竿**（新） | 特殊 | 0.12 / 0.75 / 1.3 | 1 | **夜里**咬钩 ×0.6、夜行鱼权重 ×1.5；白天无加成 | 商店 900 |
| **听雨竿**（新） | 特殊 | 0.12 / 0.75 / 1.3 | 1 | **雨天**咬钩 ×0.6、雨天鱼权重 ×1.5 | 商店 900 |
| **寒江竿**（新） | 特殊 | 0.15 / 0.75 / 1.3 | 1 | **冬天**所有鱼权重 ×1.3，冰湖银鱼王概率翻倍，冬天"手不冻"（咬钩窗口 +0.3 秒） | 成就奖励（钓到冰湖银鱼王）/ 盲盒 |
| **拾遗竿**（新） | 特殊 | 0.1 / 0.85 / 1.1 | 1 | **盲盒和宝物概率 ×2**，杂物里翻出好东西的概率提高 | 商店 1500 |
| **并蒂竿**（新） | 特殊 | 0.15 / 0.8 / 1.2 | 1 | 8% 概率**一次钓上两条同种鱼**（拉鱼只拉一次） | 盲盒 / 任务奖励 |
| **龙骨竿**（新，最高档） | 顶级 | 0.3 / 0.5 / 2.2 | **2** | 神话鱼的"入场券"之一；拉鱼绿条 +10%；所有 perk 的 30%（兼收并蓄） | **合成**：金龙竿 + 4 片「龙鳞」（来自神话鱼 / 沉船箱）+ 币 |
- 竿有**耐久吗？** 建议**不做耐久**（不惩罚玩家），特殊竿的代价是**场合限制**（夜里 / 雨天 / 冬天才有加成），所以买多根换着用。

### 5.2 配件（Tackle）：P2 做，约 6 种
| 配件 | 效果（映射到 `FightSim` / 抽鱼参数） | 价格（建议） |
|---|---|---|
| **长浮漂** | 绿条 +12% | 250 |
| **铅坠** | 绿条下沉更稳（重力小一点），适合手机连点操作 | 250 |
| **倒刺钩** | 鱼在绿条里时绿条"黏"着它（适合慢游的常见鱼），对 `dart` 型鱼无效 | 400 |
| **缓冲浮标** | 鱼不在绿条里时，进度掉得慢 35% | 600 |
| **声呐浮标** | 咬钩前就告诉你是**什么鱼**（图鉴里解锁过的才显示名字），可以决定要不要收 | 700 |
| **寻宝钩** | 盲盒 / 宝物概率 ×1.5；拉盲盒时鱼不会跑 | 800 |
- 配件**不消耗**（和竿一样永久），消耗的是饵。

### 5.3 品质星级（要不要做？）
星露谷的"完美 → 银 / 金 / 铱星"是卖价和成长的重要一环，但我们的背包是 **物品 id → 数量**，星级意味着同一种鱼要分成几个格子（`fish_x@1`…）。建议**先不做星级**，用现有的"完美 → 尺寸更大"，并在图鉴里加一栏**「完美次数」**；如果以后想做，再单独立项。

## 6. 新饵料与盲盒

### 6.1 饵料表（`bait` / `bait_pro` 保留，新增 7 种）
| 饵 | 效果 | 获得 |
|---|---|---|
| 鱼饵（现有） | 基础 | 登录送 / 10 币 ×5 |
| 香饵（现有） | 咬钩 ×0.75，稀有 ×1.25 | 30 币 ×5 |
| **夜光饵** | 夜里咬钩 ×0.7，夜行鱼 ×1.4 | 40 币 ×5 |
| **应季饵** | 当季鱼权重 ×1.5（春夏秋冬自动按当前季节） | 40 币 ×5 |
| **野饵** | 12% 概率**双份**（钓上来 ×2） | 60 币 ×5 |
| **磁铁饵** | 盲盒 / 宝物概率 ×2 | 60 币 ×5 |
| **万能饵** | **无视季节、天气、昼夜限制**（所有鱼按基础权重，神话和传说鱼除外） | 盲盒 / 合成（不卖），用来补图鉴 |
| **指名饵** | 做一份"某种鱼的饵"：下一杆**只会咬这一种**（只能做常见 / 少见 / 稀有；用 3 条那种鱼合成） | 合成 |
| **神话饵** | 神话鱼的条件之一 | 合成（龙鳞 + 稀有鱼）/ 盲盒 |
- **合成**是新的"回收口"：把没用的**杂物和常见小鱼**变成饵（比如 5 个杂物 + 1 币 → 1 个鱼饵），让垃圾有去处；合成台放在校园商店旁（P2）。
- 玩家之间能不能交易饵 / 盲盒见 §10。

### 6.2 盲盒（"钓到盲盒"）
两种来源，建议分两期：
- **A. 当作一种"渔获"（P2，简单）**：抛竿时除了鱼和杂物，还有小概率钓到**盲盒**物品，背包里点「打开」才揭晓，带一个开箱动画。服务器在**打开时**才随机。
- **B. 拉鱼时的宝箱小游戏（P3，星露谷式）**：拉鱼过程中偶尔出现宝箱图标，要让绿条同时罩住它拉满另一根进度条，成功拉上鱼后才给；**鱼跑了宝箱也没了**。更有趣但要改拉鱼界面和模拟。

**三种盲盒**（按稀有度）：
| 盲盒 | 怎么钓到 | 内容 |
|---|---|---|
| **漂流瓶** | 每杆约 4%；雨天 ×1.5 | 小额币（10–40）、鱼饵、杂物清单里的小宝物；极小概率一张"藏宝图"（纸条彩蛋） |
| **旧木箱** | 每杆约 1.2%；夜里 ×1.5 | 好饵（香饵 / 夜光 / 野饵 / 磁铁）、配件、币（50–200）、**盲盒限定鱼**；小概率称号碎片 |
| **沉船箱** | 每杆约 0.25%；暴雨夜 ×2 | 特殊鱼竿（并蒂 / 寒江）、万能饵、神话饵、「龙鳞」、稀有外观（手持物 / 头像框）、大额币（300–800） |
- **保底**：连续开 30 个没出"珍品"（稀有及以上）必出一个；防止倒霉到放弃。
- **没有任何付费**：盲盒只能钓到，不卖、不充值（项目不商用，也不要出现"抽卡"的氛围）。

### 6.3 盲盒限定鱼 / 特殊物品
- **盲盒限定鱼 5 种**（只能从盲盒里开出来，在图鉴里单独一栏「盲盒图鉴」）：被冲进湖里的观赏鱼——比如**热带灯鱼、孔雀鱼、蝴蝶鲤、七彩神仙、龙睛**；稀有度从稀有到史诗，卖价不错，喂猫好感更高。
- **特殊物品**（不一定要卖钱）：「旧校徽」「泛黄的借书卡」「生锈的饭卡」之类**校园风小宝物**（图鉴 / 收集用，部分可以交给 NPC 换东西）、**龙鳞**（合成龙骨竿和神话饵）、**手持物 / 头像框 / 称号**（沿用现有的手持物和称号系统）。

## 8. 经济平衡（先给方向，数值上线前要再算一遍）
- 现在：抛一杆期望 ≈ 12.7 币；高档竿（金龙）在稀有鱼权重上 ×1.6，大约让每杆收入涨 15–20%。
- 目标：最高档的**整套**（龙骨竿 + 配件 + 好饵）每杆收入比现在最高档再高 **约 20–30%**，不要更多；
- **币的出口**：特殊竿 900–1500、龙骨竿（合成 + 币）约 3000、配件 250–800、好饵 40–60/5 个、合成费用；这些加起来比现有的 1800 金龙竿多一大截，让币有地方花；
- **盲盒的期望值**：旧木箱约 120 币等值、沉船箱约 600 币等值（含饵 / 配件的折算），保持"开箱开心，但不是赚钱的好办法"；
- **神话鱼**每人每种一次性大奖（称号 + 约 1500 币 + 专属物品），再钓只是卖钱（1400 × 行情）；条件复杂，实际一天也钓不了几条。
- 上线后看真实余额分布和钓鱼榜再调（和现在一样，`ECONOMY.md` §6 的值本来就是推演值）。

## 9. 技术设计（草案）

### 9.1 数据表（`src/shared/`）
- `FishDef` 加：`rarity: 'mythic'`；`needs?: { bait?: string; rods?: string[]; night?: boolean; rain?: boolean; seasons?: Season[]; unlock?: string }`（神话鱼的出现条件）；`source?: 'lake' | 'box'`（盲盒限定）；`crown?: boolean`。
- `RodDef` 加：`slots`（配件槽数）、`perk`（特长：`{ night?: {wait, luck}, rain?: …, season?: …, treasure?: number, double?: number, tackleMul?: number }`）、`name / how / desc`（图鉴用）。
- 新增 `BaitDef`（现有 `PRO_BAIT` 改成表）：`wait`、`luck`、`double`、`treasure`、`ignoreEnv`、`only?: string`（指名）、`craft?`（合成配方）。
- 新增 `TackleDef`：`bar`（绿条倍率）、`sink`（下沉稳定度）、`cling`（黏鱼）、`dropMul`（进度掉得慢）、`sonar`、`treasure`。
- 新增 `BoxDef`：三种盲盒的 `loot` 表（带权重 + 保底）。
- `items.ts` 里新物品（竿、饵、配件、盲盒、龙鳞、校园小宝物）；`tools/art/items.ts` 里画图标；`tests/` 继续检查"目录 / 物品 / 图标一致"，再加：每张 `loot` 表的物品都存在、权重 > 0、保底可达。
- `rollFish(rnd, env)` 的 `env` 加：`rod / bait / tackle` 解析出的倍率、`mythicOk`（条件是否满足）、`ignoreEnv`；神话鱼的权重 = 0，除非 `needs` 全部满足。

### 9.2 玩家档案与协议（服务端部分由主人实现）
- 档案新增：**装备栏**扩成 `{rod, bait, tackle[]}`；**装备图鉴** `Saved.gd`（`{rods: {id: ts}, baits: {id: n}, tackles: {id: ts}, boxes: {id: n}}`：第一次拥有 / 使用的时间或次数）；**盲盒保底计数**；（P3）钓鱼经验 / 等级、神话鱼首次奖励已领标记。
- 协议只增不改：`equip_set` 加 `tackle`；新增 `box_open {id}` → `box_result {items[], fish?}`；`geardex_get` → `geardex {…}`；`fish_*` 消息里咬钩时带上"是否有皇冠"（`crown`）、声呐配件时带鱼名；神话鱼公告用现有的 `sys` / 公屏系统消息。
- **服务器校验**：装备必须在背包里；配件槽数不能超；开盲盒扣物品 + 服务器随机；合成扣材料；神话条件由服务器按**自己的时间 / 天气 / 季节**判断，不信客户端。

### 9.3 客户端
- **图鉴**（`CodexPanel`）：「钓鱼图鉴」页分三栏——**鱼类**（现有 + 神话 + 盲盒限定）/ **鱼竿** / **饵料与配件**，未解锁显示剪影和"怎么得到"提示，解锁后显示效果数值和获得时间；每栏有**收集进度**，集齐有奖励（称号「钓具收藏家」等）。
- **背包钓鱼装备栏**：三格（竿 / 饵 / 配件），悬停显示效果；特殊竿旁边显示"夜里 / 雨天 / 冬天"这类场合标签，当前环境满足时高亮。
- **拉鱼**（`FightSim`）：接配件参数（绿条长度、下沉、黏鱼、进度掉速）；神话鱼头顶皇冠；（P3）宝箱进度条。
- **开盲盒**面板：点背包里的盲盒 → 开箱动画 → 列出得到的东西（飞入背包）。
- **合成**面板（P2）：杂物 / 小鱼 → 饵、龙鳞 + 材料 → 龙骨竿 / 神话饵。

## 11. 风险与取舍
- **内容量**：每个新东西都要一个像素图标 + 图鉴文案；P1 约 13 个、P2 约 20 个，图标是程序化画的，量大但不难（`tools/art/items.ts`）。
- **数值平衡**：特殊竿的 perk 叠加饵和配件可能超标 → 规定"同类加成取最高、不相乘"，并在 `economy.ts` 里集中算 `effective()`，写测试防止超过上限。
- **神话鱼太难 / 太易**：条件和难度会按上线后的数据调；先做 3 条，别一次放太多。
- **盲盒氛围**：不收费、不能买、保底可见；开箱结果清楚显示概率范围（图鉴里写"可能开出什么"），避免"黑箱感"。
- **玩家之间交易**：竿 / 配件 / 饵能不能交易？建议**饵和普通鱼可以、特殊竿 / 万能饵 / 神话饵 / 盲盒不可交易**（防倒卖和"代开箱"），在 §12 拍板。
