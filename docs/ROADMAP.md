## 三、技术债与工程
- [ ] 拆分大文件：`WorldScene.ts` 等大文件（按小猫/钓鱼/商店/校园墙分模块），减少多人协作冲突。
- [ ] Vite 构建拆包（Phaser 单独 chunk，缓存更友好）。
- [ ] AOI 改空间网格（上千人时才需要）；若做竞技/抢资源，移动改服务器模拟。
- [ ] CI 加缓存与"手动触发部署"按钮（只在想要时做；自动部署需要把服务器密钥交给 GitHub，风险大）。
- [ ] 私有仓库没有分支保护：想强制"必须 PR + CI 通过才能合并"需升级 GitHub Pro 或公开仓库。

## 四、明确不做 / 暂缓
- 账号密码体系（身份 = 浏览器 token + 备份码）。
- 对战/攻击、湖里游泳（要服务器模拟，收益低）。
- 真钱充值/提现、第三方素材（项目不商用、美术全程序化）。
