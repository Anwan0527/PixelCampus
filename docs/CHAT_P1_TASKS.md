# 聊天频道 P1 任务拆分（2026-11-05）

> 上游方案：[CHAT_CHANNELS_PLAN.md](CHAT_CHANNELS_PLAN.md)（已拍板：先 P1 再 P2、好友互拉、站长查记录、关闭 = 不收 + 另有静音）。
> 这份文档把 **P1「频道底座」** 拆成可以直接开工 / 认领的任务。服务端那一半由主人做，细节在私有文档里；这里写**双方都要遵守的协议契约**和**客户端、共享、测试**任务。

## 1. P1 范围

**做**：`world` 世界 · `near` 附近 · `party` 队伍 · `sys` 系统 四个频道；每个频道的**开 / 关**和**静音**（存档案、换设备也在）；聊天窗口**频道标签条 + 未读数**；`/w /n /p` 前缀命令；**屏蔽按接收人过滤**（全频道）；**队伍聊天**；管理员「公屏记录」页的**频道筛选**；举报带频道。

**不做（留给 P2 / P3）**：群聊、年级频道、置顶排序、历史翻页（`ch_history`）、已读同步（`ch_read`，P1 的未读数只在本机统计）、@提及、私聊并入同一窗口。宿舍 / 室内里的聊天（`room_*`）P1 不动，仍按现状。

## 2. 协议契约（先定，双方都按它写）

### 2.1 共享类型（新增 `src/shared/channels.ts`）
```ts
export type ChannelId = 'world' | 'near' | 'party' | 'sys';
export interface ChannelMeta { id: ChannelId; name: string; icon: string; color: string; sendable: boolean; defaultOn: boolean }
export const CHANNELS: Record<ChannelId, ChannelMeta>;   // world 🌍 / near 📍 / party 👥 / sys 🔔（sys 不能发言）
export interface ChannelPrefs { off?: 1; mute?: 1 }       // 每个频道一份；没有 = 开、不静音
export type ChannelPrefsMap = Partial<Record<ChannelId, ChannelPrefs>>;  // 存在玩家档案的 `Saved.ch`
export function cleanChannelPrefs(v: unknown): ChannelPrefsMap;          // 读档 / 收消息时清洗：只认已知频道、只认 off/mute
export function parseSlash(text: string): { ch?: ChannelId; text: string; unknown?: string };  // "/p 你好" → { ch:'party', text:'你好' }
```
- `sys` 是**客户端本地频道**：所有 `{t:'sys'}` 消息和 `net.system()` 的提示都进它，服务器不需要为它转发任何东西（只记它的开 / 关 / 静音偏好）。
- 前缀：`/w` 世界、`/n` 附近、`/p` 队伍（别名 `/世界 /附近 /队伍`）。`/` 开头但不认识 → `unknown` 返回，客户端提示"没有这个频道"，不发送。

### 2.2 消息（`src/shared/protocol.ts` 只增不改；**`PROTOCOL_VERSION` 8 → 9**，旧页面被要求刷新一次，避免队伍的话漏进老页面的公屏）
**客户端 → 服务器**
| 消息 | 含义 |
|---|---|
| `chat { text, ch? }` | `ch` 不写 = `world`；`sys` 不能发 |
| `ch_get` | 要我的频道状态（进游戏、重连时客户端不需要主动要：服务器在 `welcome` 后主动发一次） |
| `ch_set { ch, on?, mute? }` | 改某个频道的开关 / 静音；`on:false` = 关；服务器清洗后存档并回 `channels` |

**服务器 → 客户端**
| 消息 | 含义 |
|---|---|
| `chat { …现有字段, ch? }` | `ch` 不写 = `world`；`party` 的话气泡颜色不同 |
| `channels { items: ChannelState[] }` | 我当前**有哪些频道**和各自状态；登录、组队 / 退队、切世界、`ch_set` 之后都会发 |
| `ch_result { ok, msg }` | 操作失败时的提示（如"先把这个频道打开"） |
```ts
export interface ChannelState { id: ChannelId; on: boolean; mute: boolean; /** 频道里现在有多少人（world = 世界人数，party = 队伍人数，near 不报） */ n?: number }
```
- **`party` 只在有队伍时才出现在 `channels` 里**，队伍解散就从列表里消失（客户端据此显示 / 移除标签，并清掉它的消息缓冲）。
- `world` / `near` / `sys` 永远在列表里。
- `chat_history`（进游戏的最近 100 条）**只属于 `world`**，格式不变。
- 举报：`report { kind: 'chat', ref: mid, ch? }`，`ch` 不写 = `world`（客户端 `ReportDialog` 要带上，服务器按频道取证据）。
- 管理员：`adm { op: 'log_chat', ..., ch? }` 加频道筛选；`AdminChatItem` 加 `ch?`（不写 = `world`）。

### 2.3 语义（双方要一致）
- **接收规则**：`world` = 当前世界的成员（和现在一样：个人世界只回显给自己）；`near` = **同一世界里能看见发言人的玩家 + 自己**（用现有视野判断）；`party` = 队伍成员（个人世界里也收得到）。一条话**只属于一个频道**，不会同时出现在世界里。
- **关闭 = 不收也不能发**：频道对我"关"了，服务器不再给我发这个频道的话；我在里面发言，服务器回 `ch_result {ok:false,"先把这个频道打开"}`。**静音**只影响客户端：仍收，不弹小条 / 不冒气泡，只涨未读数。
- **屏蔽**：我屏蔽的人，他的话在**所有频道**都不发给我（服务器按接收人过滤）。
- **全局规则不变**：禁言 `mu`、敏感词、隐身不能发言对所有频道一样生效；"关闭公屏"只管 `world` 和 `near`。限频是**所有频道共用一份**（防止换频道绕过）。
- **默认**：四个频道都是开、不静音；老档案没有 `Saved.ch` = 全默认。

## 5. 联调验收清单（两个浏览器窗口 + 本机服务器，逐条过）
1. **世界频道和现在一样**：A、B 在公共世界，A 发话 B 能看到；个人世界只回显自己。
2. **附近**：A、B 在同一个视野里，A 用 `/n 你好`，B 收到；B 走远（看不见 A）后 A 再发，B 收不到；B 的世界频道没有这条。
3. **队伍**：A 邀请好友 B 组队，两边多出 `👥队伍` 标签；A 用 `/p` 发话，只有 B 看到，气泡颜色不同；**A 在个人世界里 B 也收得到**；队伍解散后标签消失，并有一条系统提示。
4. **关闭频道**：B 关闭 `world`，A 在世界里说话 B 收不到（服务器没发）；B 想在世界里发言被提示"先把这个频道打开"；B 重新打开后恢复。
5. **静音**：B 静音 `party`，A 在队伍里说话，B 不弹小条、不冒气泡，只在标签上涨灰色未读数；切到该标签后清零。
6. **屏蔽**：B 屏蔽 A 之后，A 在世界 / 附近 / 队伍里说的话 B 全都看不到。
7. **禁言 / 关公屏**：A 被禁言后三个频道都发不出去；管理员"关闭公屏"后 `world` 和 `near` 发不出去，`party` 不受影响。
8. **系统频道**：欢迎语、"已连上服务器"、好友上线提示都在 `🔔系统` 标签里，不再混进世界；系统频道不能发言。
9. **持久化**：B 关掉某频道 → 刷新页面 / 换浏览器恢复身份后仍是关闭状态。
10. **管理员**：「公屏记录」能按频道筛选；对队伍里的话点 ⚑ 举报，管理员举报页能看到"频道：队伍"和上下文；撤回对三个频道都有效。
11. **旧页面**：不刷新的旧页面连上新服务器会被要求刷新，不会看到队伍的话漏进公屏。
12. **横屏**：812×375 下标签条、输入框、⚙ 都能用，聊天框在屏幕顶部。

## 6. 风险与注意
- **串频道**是最大风险：接收人只在服务端一个出口里解析，务必有测试覆盖"每个频道只发给该收到的人"。
- 附近 = 视野范围（约 1000 像素，大半个屏幕），不是"贴身"；如果觉得太大，P3 再加半径。
- 协议版本变了，老页面会被强制刷新一次，部署前要在公告里说一声（可选）。
- 标签条在小屏占一行：标签可横向滑动，收起（手机）时不占位。
