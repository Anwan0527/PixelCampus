## 1. 背景与目标

现有战斗都是一对一。组队 PVE 让好友队伍（最多 4 人）一起打一个共享血条的 BOSS，补上「多人协作」的玩法。

目标：

- 好友组队后可以一起挑战精工湖的 BOSS。
- 所有人都能看到同一个 BOSS 血条、阶段变化、队友状态。
- 每人都能出招 / 换精灵；BOSS 在所有人行动后反击。
- 全员倒下才失败；首次击杀有奖励。

## 2. 用户与场景

- 玩家在公共世界组队（现有 Party，最多 4 人，必须好友）。
- 队长或任一队员走到**精工湖中心小岛**的入口，按 E 发起挑战。
- 队伍成员收到确认提示，全员同意后进入。
- 战斗：每人选一只精灵上场（默认队伍第 1 只），各自出招；BOSS 共享血条。
- 打完回到入口，BOSS 回满血。

## 4. 正向场景

- **P1.** 4 人组队走到精工湖入口，队长按 E 挑战，队员收到确认，全员接受后进入战斗。
- **P2.** 战斗界面显示 BOSS（名字 + 等级 + 共享血条 + 阶段提示）、队友列表。
- **P3.** 每人选精灵上场，各自出招；BOSS 血条对所有人同步减少。
- **P4.** BOSS 血量到 70% → 阶段 2（攻击提升、技能变化），界面提示。
- **P5.** BOSS 血量到 40% → 阶段 3。
- **P6.** 某玩家全部精灵倒下 → 他的战斗结束（不能再出招），但队伍继续；其他人还能打。
- **P7.** 全员倒下 → 挑战失败，回到入口。
- **P8.** BOSS 血量归零 → 胜利；首次击杀给奖励，参与者都收到。
- **P9.** 重复击杀 → 按人数平分少量币。
- **P10.** 任一玩家超时 → 自动跳过该回合，BOSS 照常反击。
- **P11.** 某玩家断线 30 秒内回来 → 回到战斗继续。
- **P12.** 断线超过 30 秒 → 该玩家退出战斗，其他人继续。

## 5. 反向 / 异常场景

- **N1.** 客户端**绝不能**自行结算 BOSS 伤害或判定胜负。
- **N2.** 服务器**绝不能**接受不在队伍里 / 不在入口附近 / 不在公共世界的挑战。
- **N3.** 同一队伍**绝不能**同时开两场 BOSS 战。
- **N4.** 同一玩家**绝不能**同时参与 PvE 和 PvP。
- **N5.** BOSS 血量**绝不能**低于 0 或超过上限。
- **N6.** 阶段**绝不能**重复触发（只从高血到低血一次）。
- **N7.** 已退出的玩家**绝不能**继续出招或收到奖励。
- **N8.** 超时**绝不能**让战斗卡死。
- **N9.** 断线重连**绝不能**重复结算或额外获得回合。
- **N10.** 奖励**绝不能**重复发放（同一次击杀只发一次）。
- **N11.** 全员断线**绝不能**让 BOSS 保持残血。
- **N12.** 玩家可见文字**绝不能**用 `innerHTML`。
- **N13.** BOSS 战**绝不能**影响玩家存档血量（战斗用满血副本）。

## 6. 数据 / 协议

### 6.1 内容

- `src/shared/boss.ts`：BOSS 定义（物种、等级、阶段、倍数、奖励）。
- BOSS 用 `o09` 青鳞，名字「精工湖·青鳞」；等级 30；阶段 2 / 3 的属性或技能变化。

### 6.2 协议（C→S）

```ts
| { t: 'boss_challenge' }
| { t: 'boss_reply'; uid: number; accept: boolean }
| { t: 'boss_act'; bid: string; turn: number; a: PvpAction }
| { t: 'boss_leave' }
```

### 6.3 协议（S→C）

```ts
| { t: 'boss_invite'; uid: number; name: string; ms: number }
| { t: 'boss_state'; bid: string; turn: number; phase: 'choose' | 'over'; boss: BossView; players: BossPlayerView[]; ev: BEvent[]; result?: ... }
| { t: 'boss_end'; bid: string; result: 'win' | 'lose' | 'left'; msg: string; reward?: { coins: number; items?: { id: string; n: number }[] } }
```

### 6.4 存档

- `MonSave` 增加 `boss?: { first: boolean; kills: number }`（是否首杀、击杀次数）。
- 旧存档缺字段按 `{ first: false, kills: 0 }`。

## 7. 界面

- 邀请：复用 PvP 的邀请条样式。
- 战斗：复用 `BattleUi` 的 BOSS 卡片（单人视角）+ 队友列表（头像 + 血量 + 是否倒下）。
- 阶段：血条下方显示「第 N 阶段」。

## 8. 服务端

- `server/boss.ts`：挑战会话、玩家列表、共享血条、阶段、超时、断线、奖励。
- 复用 `src/shared/pvp.ts` 的结算思路（多玩家共享一场）。
- 与 PvP / PvE 会话互斥。
