## 3. 关键规则：加鱼不改变各档的出现概率
现在每一档的总权重大致是：常见 114、少见 44、稀有 16.2、史诗 2.9、传说 0.34，杂物 16。**新加鱼不能把稀有鱼的整体概率摊薄 / 抬高**，所以：
- `fishing.ts` 增加一张 `TIER_TOTAL`（上面这几个数），`rollFish` 抽鱼时每条鱼的有效权重 = `weight × TIER_TOTAL[档] / 该档鱼的权重之和`（只算"湖里的鱼"，盲盒限定鱼和神话鱼不参与）；
- 条件倍率（夜 / 雨 / 季）仍然只乘在单条鱼上，所以"秋天螃蟹变多"依然成立；
- 测试：任意加减一条鱼，各档的出现概率（在中性环境下）不变；各档的期望卖价变化在 ±10% 以内（防止新鱼把经济带偏）。

## 4. 图鉴设计（借鉴星露谷的"收藏"页）

星露谷的鱼类收藏页对每条鱼写清楚：**在哪里、什么时间、哪个季节、什么天气、难度 / 游法、最大尺寸记录**；另外还有"收集包（bundle）"和"钓过 N 种鱼"的成就。我们对应做：

### 4.1 三栏结构（鱼竿和饵料在鱼类下面）
**钓鱼图鉴** = 三个子页 + 若干视图：
1. **鱼类**：分组标签 `常见 / 少见 / 稀有 / 史诗 / 传说 / 神话 / 盲盒限定`（神话、盲盒限定在没解锁前只显示"？？？"和获取提示）；每个格子：图标（没钓到 = 剪影）、名字、条数角标。
2. **鱼竿**：9 根竿，每根显示：特长、三个数值（难度 / 咬钩 / 幸运）、配件槽数、获得方式；没拥有 = 剪影 + "怎么得到"。
3. **饵料与配件**：9 种饵 + 6 种配件，同样的卡片；饵显示"用过几次"，配件显示"是否拥有"。

### 4.2 鱼的详情页（点开一个格子）
- 基本：稀有度（颜色）、描述（一句真实知识）、**卖价区间**（含今日行情）；
- **习性**（解锁后显示，对应星露谷的"地点 / 时间 / 季节 / 天气"）：钓点（现在只有「精工湖」，P3 加钓点后这里分区）、**时段**（白天 / 夜里 / 全天）、**季节**（四个小图标，出现的亮、不出现的灰）、**天气**（晴 / 雨）；
- **难度与游法**：**1–5 颗星**（由 `fightOf` 的基础难度换算）+ 游法图标（慢游 / 时快时慢 / 突然窜动）；
- **我的记录**：首次钓到的日期、累计条数、**最大尺寸（厘米）、最重一条（公斤）、「完美」次数**、最近一次钓到；达到「巨物」个头的鱼贴一个徽章；
- 神话鱼：解锁条件 + 当前满足了哪几条（✔ / ✘），例如"神话饵 ✘、寒江竿 ✔、冬天夜里 ✘"；
- 盲盒限定鱼：写"只能从盲盒里开出来"。

### 4.3 视图与筛选
- **「现在能钓到什么」**（今日可钓）：根据现在的**季节、昼夜、天气**，把当前出现概率 > 0 的鱼列出来，按"现在最容易遇到"排序，并标出还没钓到的；这是新手最需要的信息。
- **筛选**：只看未钓到 / 只看某个季节 / 只看夜里 / 只看雨天。
- **收集进度条**：每档一条（和现在一样），总进度 `x / 48`。

### 4.4 收藏册与里程碑（借鉴"收集包"和"钓过 N 种鱼"的成就）
- **钓鱼册页**（8 组收集，集齐一组领一次奖励，奖励 = 币 / 好饵 / 配件）：春季鱼、夏季鱼、秋季鱼、冬季鱼、夜行鱼、雨天鱼、大个头（每档各钓过一条「特大」及以上）、贝壳与甲壳（河蚌 / 河蟹 / 河虾 / 小龙虾 / 中华鳖）。
- **里程碑**（钓到不同种类的鱼）：**10 / 25 / 40 / 全部（48）**，各给称号或币；原来的「钓鱼大师」改成"全部（48 种）"，新增「钓到 10 种」「25 种」「40 种」成就。
- 额外成就：**第一条神话鱼**、**三条神话鱼全集齐**（称号「镇湖三宝」）、**打开第 N 个盲盒**、**集齐所有鱼竿 / 所有饵**。

## 5. 其他需要的小物件
- **珍珠**：河蚌有 3% 概率开出一颗；可卖（约 120 币）、也能当合成材料（神话饵的辅料）。
- **龙鳞**：神话鱼首次奖励 + 沉船箱；合成龙骨竿 / 神话饵。
- **校园小宝物 4 件**（盲盒里的收藏品，可卖也可留着）：旧校徽、泛黄的借书卡、生锈的饭卡、校史残页。

## 6. 文案与体验小点
- 稀有 / 史诗里带"保护动物"设定的鱼（胭脂鱼）：钓到后弹一个"要不要放生？"——放生给一点好感 / 币，不放生照常卖（只是文案和一个小选项，P2 末尾做）；
- 外来入侵种（雀鳝、大口黑鲈）：图鉴描述里提一句"不该出现在这里"，有点环保彩蛋；
- 白鲟这类已灭绝 / 濒危的传说鱼：描述写成传说口吻，不写"真实存在"。

## 10. 联调验收清单（真服务器 + 两个浏览器，逐条过）
1. **新鱼出现**：每档新鱼能在对应的季节 / 昼夜 / 天气下被钓到；各档整体概率没变（统计 2000 杆）。
2. **图鉴**：三个子页都能打开；没钓到的是剪影、钓到的显示习性 / 难度星 / 记录；"现在能钓到什么"随季节 / 昼夜 / 天气变化。
3. **装备栏**：三格；配件槽数超限被拒；换竿换饵立刻在下一杆生效；特殊竿的场合标签高亮。
4. **特殊竿**：萤火竿夜里咬钩明显更快、白天无加成；听雨竿雨天同理；并蒂竿约 8% 钓双份；拾遗竿盲盒概率翻倍。
5. **饵**：夜光 / 应季 / 野饵 / 磁铁各自生效；万能饵让"不在当季"的鱼也能出（神话 / 传说除外）；指名饵只咬指定的鱼，用一次少一个。
6. **配件**：长浮漂绿条变长、铅坠下沉更稳、倒刺钩对慢鱼黏条、缓冲浮标进度掉得慢、声呐在咬钩时显示鱼名。
7. **神话鱼**：条件不满足钓不到；满足后（河工锦：锦鲤 ≥ 20 + 春季白天 + 香饵 + 碳素竿）出现，头顶有皇冠；钓到后**全服公告**、首次奖励只给一次，再钓只是卖钱。
8. **盲盒**：漂流瓶 / 旧木箱 / 沉船箱能钓到；打开才揭晓；保底在第 30 次内触发；盲盒限定鱼进图鉴的"盲盒限定"栏。
9. **合成**：杂物 → 鱼饵、同种鱼 → 指名饵、龙骨竿、神话饵；材料不够被拒；合成后背包正确。
10. **交易**：特殊竿 / 万能饵 / 神话饵 / 盲盒 / 龙鳞在交易里加不进去；饵和普通鱼可以。
11. **册页与里程碑**：集齐一组领奖一次；钓到 10 / 25 / 40 / 全部种类触发成就。
12. **持久化与兼容**：下线重连、换设备恢复身份后装备 / 图鉴 / 盲盒保底都在；老档案（没有新字段）正常。
13. **经济**：卖神话鱼 / 珍珠 / 小宝物价格正确；喂猫好感正确。
14. **手机**：图鉴三栏、装备栏、开盲盒面板在 360×740 竖屏和 812×375 横屏都能用。
15. **旧页面**：协议版本变了，旧页面被要求刷新。

## 11. 风险与注意
- **图标量大**（51 个）：全是程序化像素图，量大但不难；先出占位（用 `fish()` 助手改色）再逐个精修，不阻塞开发。
- **数值叠爆**：竿 + 饵 + 配件同类取最高并设总上限，`resolveGear` 有单元测试兜底；上线后看钓鱼榜和余额分布再调。
- **老玩家的图鉴分母变了**（25 → 48）：集齐「钓鱼大师」的老玩家需要提醒（改名「钓遍精工湖」做老版本的称号，保留；新的"全部 48 种"给新称号），文案里说清楚，避免被误会"退步"。
- **神话鱼条件复杂**：图鉴里每条条件都实时显示 ✔ / ✘，避免玩家不知道缺什么。
- **盲盒氛围**：不收费、不能买、掉落表和保底进度公开显示。
