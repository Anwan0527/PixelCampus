## 2. ① 钓鱼等级与经验

### 2.1 经验来源（服务器在 `fishCatch` 里结算，每次钓到才给）
| 稀有度 | 常见 | 少见 | 稀有 | 史诗 | 传说 | 神话 | 杂物 |
|---|---|---|---|---|---|---|---|
| 基础经验 | 1 | 2 | 5 | 12 | 30 | 100 | 0 |

- **完美拉鱼 +50%**（向下取整，至少 +1）；**双钓**两条都算。
- **图鉴新种类（第一次钓到）额外加**：`max(5, 基础 × 2)`，神话额外 +200（所以第一条神话鱼一次给 300）。
- 盲盒里开出的限定鱼：只拿「新种类」那份额外经验（不当作钓到）。
- 每周委托完成再给一份经验（见 §3）；放生给 50% 的基础经验（见 §4）。
- 平均每条鱼约 1.7 经验（按各档出现概率算），所以**新种类的额外经验是前期升级的主力**。

- **10 级**：约 1800 经验。一个月钓 25 种左右的普通玩家，前期靠「新种类」就拿了几百经验，再钓 700 条上下，活跃玩家约一周多到两周。
- **30 级**：21200 经验，约 12000 条的量级，是真正的长线，不期望短期有人到。
- 公式和表都在 `src/shared/fishlevel.ts`，上线后看分布可以只改一个常数。

### 2.3 等级奖励（每级都有一点，关键级有大的）
| 奖励类型 | 内容 |
|---|---|
| **每级** | 升级就送 `10 × 级数` 校园币（最多 200）+ 香饵 ×3（6 级以前送普通鱼饵 ×5） |
| **绿条加成**（累计，最多 +5%） | 4 级 +2%、8 级 +3%、14 级 +4%、22 级 +5%；和配件 / 竿的绿条加成相加，仍受总上限 +30% 约束 |
| **合成配方解锁** | 1 级：杂物换鱼饵；2 级：小鱼做鱼饵；**5 级：指名饵**；**10 级：神话饵**；**12 级：龙骨竿**；**7 级新增「香饵自制」**（鱼饵 ×3 + 小鱼 ×2 → 香饵 ×2）；**13 级新增「夜光饵自制」**（鱼饵 ×3 + 河虾 ×2 → 夜光饵 ×2） |
| **称号 / 成就**（各带币） | 5 级「湖边学徒」+50 币；10 级「老钓手」+150；15 级「钓鱼达人」+300；20 级「钓鱼宗师」+600；25 级「渔圣门徒」+900；30 级「渔圣」+1500 |
| **路线选择** | 5 级、10 级各解锁一个「路线」槽（见 2.4） |

> **老玩家的初始经验按图鉴折算**：第一次登录新版本时，用图鉴记录算（每种鱼 `n 条 × 基础经验` + 每个已有种类的新种类奖励），所以已经钓了很多的人直接是合理的等级，不会被配方门槛卡住（同时静默补发等级称号和成就，不弹一堆提示）。

### 2.4 路线选择（5 级、10 级各一个槽，随时免费切换）
- 每个槽二选一：**渔夫**（卖鱼价 **+10%**）或 **寻宝**（盲盒概率 **×1.3**，加算，见下）。
- 两个槽**叠加**：两个都选渔夫 = 卖鱼价 **+20%**（上限）；两个都选寻宝 = 盲盒 **×1.6**（`1 + 0.3 + 0.3`，仍受盲盒总上限 ×3）；一个一个 = 各 +10% / ×1.3。
- 没选之前没有加成；升到 5 / 10 级时提示一次「去选路线」。选择存在服务器，随时可以改，没有冷却和费用。
- **卖价加成只算鱼和钓上来的杂物**（不含垃圾桶里翻出来的 U 盘等），在 `Progress.sell` / `sellBulk` 里乘上；价格表（`sellList`）显示加成后的价。
- **经济风险**：这是新的币产出，所以上限是死的（+20%）；上线后看钓鱼榜和余额分布，要调只改常数。

### 2.5 界面
- **钓鱼图鉴新增第五个子页「🎣 等级」**：当前等级、经验条（xp / 本级需要）、30 级的奖励一览（已达到的打勾）、两个路线槽的切换按钮、本周放生次数与称号进度。
- **背包装备栏顶上**加一行小字：`钓鱼 Lv.7 ▮▮▮▯▯ 62%`，点一下跳到「等级」页。
- **钓到鱼的卡片**显示「+N 经验」（新种类、完美有分项）；升级时弹横幅「🎣 钓鱼升到 Lv.N」+ 奖励说明 + 提示音；升到 5 / 10 级提示「选择路线」。

## 3. ② 钓具老板（NPC + 摊子）与每周委托

### 3.1 位置与外观
- **精工湖岸边**一个**固定的 NPC「钓具老板」**（不游走，站在摊子后面，头顶有名字牌）+ 一个**摊子**（新的像素道具，遮阳伞 + 木桌 + 鱼竿架 + 木桶，约 4×3 格）。
- 位置：湖的一处平整岸边（靠近玩家现在常钓鱼的地方、有路可达，不挡道）。**具体格子开工后我先在浏览器里走一圈挑 2–3 个候选，截图给主人定**；坐标写在一个常量文件 `src/shared/fishstall.ts` 里（和图书馆广场的 `plaza.ts` 同一个做法），地图编译会据此放摊子、加碰撞、加互动区、加传送地标，主人以后想挪只改这一处。
- NPC 用现有的人物外观（挑一个戴帽子的老渔夫风格的 look），名字牌「钓具老板」；摊子上方有一个 `！` 小图标：有**可领取的委托奖励**时亮。
- 靠近摊子（互动区内）按 **E**（手机点互动键）：先说一句话，再打开**钓具摊**面板。

### 3.2 钓具摊面板（和图书馆商店共用 `ShopPanel`，换一个模式）
| 页 | 内容 |
|---|---|
| **本周委托** | 3 个委托 + 进度 + 「领取」按钮 + 全部完成的额外奖励（见 3.3） |
| **买钓具** | **钓鱼相关的全部商品**：全部鱼饵（鱼饵、香饵、夜光、应季、野饵、磁铁）、全部商店鱼竿（竹节、碳素、萤火、听雨、拾遗、金龙）、6 个配件；价格和图书馆商店一致 |
| **合成** | 和图书馆商店一样的全部配方（受 §2.3 等级门槛约束） |
- **图书馆广场的商店完全不变**（继续卖猫粮、猫窝、零食包等，继续收鱼）。
- **摊子不收鱼**（默认，见 §9-1）：卖鱼仍然去广场商店；摊子管「买、合成、领委托」。

### 3.3 每周委托（每周 3 个，全服一致）
- **周编号**：东八区**周一 0 点**换周，`weekNo(day) = floor((day + 3) / 7)`（`day` 是已有的日期编号，1970-01-01 是周四）。
- **生成**：用周编号做种子（和 `dailyQuests` 同一套思路），从模板池按难度各抽 1 个：**简单 / 中等 / 困难**；同一周所有人一模一样，聊起来是同一批。
- **进度**：服务器在**钓到、完美、开盲盒**等事件里累计，只统计**本周**；**自动计数，不用交鱼**；做完后回摊子「领取」。
- **模板池**（具体数值在 `src/shared/commissions.ts` 里，可以调）：

| 类型 | 例子（简单 → 困难） | 备注 |
|---|---|---|
| 尺寸 | 钓一条 ≥ 个头范围 60% 的鲤鱼 → ≥ 90% 的某条稀有鱼 | 只选湖里的常见 / 少见 / 稀有鱼，按该种鱼的 `minCm–maxCm` 折算，不会出现不可能的尺寸 |
| 夜里 | 夜里钓到 5 条 → 12 条 | 按服务器时间的昼夜 |
| 雨天 / 季节 | 雨天钓到 3 条 → 在冬天钓到 5 条 | 本周一定会出现各种天气和季节，但不保证连续，所以数目偏小 |
| 饵 | 用夜光饵钓到一条少见以上 → 用指名饵钓到指定的鱼 | 鼓励尝试新饵 |
| 种类数 | 本周钓到 5 种不同的鱼 → 10 种 | |
| 完美 | 完美拉鱼 2 次 → 6 次 | |
| 稀有 | 钓到 1 条稀有及以上 → 3 条 | |
| 盲盒 | 开 2 个盲盒 → 6 个 | |

- **奖励**（每个委托）：
  - 简单：150–250 币 + 鱼饵包；中等：300–450 币 + 好饵（夜光 / 应季 / 野饵 / 磁铁 ×5）；困难：500–800 币 + 配件或龙鳞 / 珍珠（小概率）。
  - 每个委托同时给**钓鱼经验**（30 / 60 / 120）。
  - **三个全部完成**：额外一个**旧木箱** + 100 经验 + 累计「全勤周数」（后面可以做称号）。
- 做不完不惩罚；周一换新，上周没领的**作废**（界面写清楚）。

## 4. ③ 放生

- **保护动物名单**（`src/shared/release.ts`，默认 4 种，见 §9-2）：胭脂鱼、白鲟、娃娃鱼（大鲵）、鲟鱼——现实里都是国家保护动物。
- **什么时候出现**：钓到名单里的鱼时，渔获卡片上多一个**「放生」**按钮（和「收下」二选一，不点就是收下，卡片自动消失）；**背包里点开这些鱼的详情也有「放生」按钮**（卡片错过了也能放）。
- **效果**：服务器扣掉这一条（必须在背包里）→ 给**少量币**（卖价的约 25%，向下取整，至少 5 币；神话没有保护动物所以不涉及）+ **50% 的基础经验** + **累计放生次数 +1**；图鉴记录不受影响（钓到的那一刻已经记过了）。
- **称号**：放生 5 次「护鱼人」、20 次「水域守护者」、50 次「生态卫士」（各带一点币）。
- **文案**：放生时弹一句科普（例如「胭脂鱼是国家二级保护动物，放回水里它们才能长成大鱼。」），不说教，一句话。
- 放生次数在「等级」页显示；不做每日上限（背包里的鱼数量本身就是上限，不能刷）。

## 5. ④ 精工湖传送点

- 传送面板（`TeleportPanel`）新增一项 **「精工湖钓具摊」**，放在新分组「湖边」（`TELEPORT_GROUPS` 补上这一组）；点了把玩家传到**摊子前面**（老板身边，服务器 `standNear` 找真能站的位置，沿用现有的冷却、状态限制）。
- 地标 `fish-stall` 由 `fishstall.ts` 的坐标在地图编译时写进 `world.json` 的 `pois`，所以主人在编辑器里挪摊子时传送点跟着走。
- 传送过去就能直接按 E 打开钓具摊，再走两步就是钓鱼的岸边——一条龙。

## 6. 数据与协议（协议版本 10 → 11）

**档案新增字段（全部可选，老档案不受影响）**
- `fx`：`{ xp: number, rt: ['fisher'|'finder'|'', 'fisher'|'finder'|''], rel: number /* 放生次数 */, wk: number /* 全勤周数 */ }`
- `wq`：`{ week: number, prog: Record<委托id, number>, done: string[], claimed: string[] }`（换周自动重置）

**消息**（只增不改）
| 方向 | 消息 | 说明 |
|---|---|---|
| C→S | `fx_get` / `fx_route {slot: 0\|1, route}` | 取等级信息 / 切换路线 |
| S→C | `fx {xp, lv, rt, rel, next}` | 等级信息；升级时带 `up: {from, to, gains}` |
| C→S | `wq_get` / `wq_claim {id}` | 取本周委托 / 领取 |
| S→C | `wq {week, list: [{id, prog, goal, done, claimed}], all: boolean}` / `wq_result {ok, msg, gain}` | |
| C→S | `fish_release {id}` | 放生（卡片和背包都发这条） |
| S→C | `release_result {ok, msg, coins, xp, rel}` | |
| S→C | `fish_state` catch 多带 `xp`（含分项 `base / perfect / isNew`）、`lv`（升级后的等级） | |
- `shop_buy` / `craft` 服务器按**离哪个摊子近**决定模式：靠近图书馆商店 = 全部商品；靠近钓具摊 = 只能买钓具（服务器的白名单 `FISH_GEAR_IDS`）；**合成两处都可以**；卖鱼只有图书馆商店。

**共享文件（`src/shared/`）**：`fishlevel.ts`（经验表、等级、奖励表、路线加成）、`commissions.ts`（周编号、模板池、`weeklyCommissions(week)`、进度判定）、`release.ts`（保护名单、放生奖励）、`fishstall.ts`（摊子 / NPC / 传送点位置常量）。`craft.ts` 给配方加 `minLevel`；`economy.ts` 的 `sellPrice` 加 `bonus` 参数；`gear.ts` 的 `resolveGear` 接收「寻宝」路线倍率和等级给的绿条加成。

## 8. 联调验收清单（真服务器 + 两个浏览器）
1. **经验**：钓常见 / 稀有各一条，经验分别 +1 / +5；完美拉鱼 +50%；新种类额外 +；双钓两条都算；杂物 0；盲盒限定鱼只加新种类那份。
2. **升级**：到 2 / 5 / 10 级时弹横幅、发币和饵、5 / 10 级提示选路线；等级称号和成就按时出现。
3. **路线**：5 级选渔夫 → 卖鱼价 +10%；10 级再选渔夫 → +20%（不再高）；改选寻宝 → 盲盒概率相应变化；随时切换，立即生效；U 盘价格不变。
4. **老玩家折算**：用一个旧档案（图鉴里有鱼）登录，等级合理；没有重复弹一堆升级提示。
5. **配方门槛**：低级号合成「神话饵」被拒并写「要 10 级」；够级后可以。
6. **钓具老板**：在湖边能找到摊子和 NPC，不压水、不挡路；E 打开面板；离远了买 / 合成 / 领取都被拒；摊子不能卖鱼，广场商店不变。
7. **买钓具**：摊子的商品是全部鱼饵 / 鱼竿 / 配件，价格和广场商店一致；猫粮、猫窝等不在摊子里。
8. **每周委托**：三个委托全服一致；进度随钓鱼累计；做完才能领、只能领一次；换周（可用测试里的时间注入）自动换新、旧的作废；全部完成给旧木箱 + 全勤计数。
9. **放生**：钓到胭脂鱼出现「放生」按钮；放生后背包少一条、得币、得经验、次数 +1；背包里没有时不能放；非保护动物没有这个按钮；累计 5 次拿称号。
10. **传送**：传送面板有「湖边 → 精工湖钓具摊」，传过去站在老板身边，冷却和限制照旧。
11. **手机**：钓具摊面板、等级页、放生按钮在 360×740 竖屏和 812×375 横屏都能用；沉浸模式里能互动。
12. **兼容**：协议 11，旧页面被要求刷新；老档案没有 `fx` / `wq` 正常；服务器重启后等级、路线、委托进度都在。

## 9. 我按默认值定了、请主人看一眼的小决定（不回复就按默认做）
1. **钓具摊收不收鱼？** 默认**不收**（保留广场商店的作用，摊子管买 / 合成 / 委托）。想收的话改一个开关，价格可以和广场一样。
2. **保护动物名单**：默认 **胭脂鱼、白鲟、娃娃鱼、鲟鱼**（你提的是前两个，后两个现实里也是保护动物）。
3. **两个路线槽叠加**：默认叠加（渔夫总 +20%、寻宝总 ×1.6）；如果觉得叠加太强，可以改成两个槽只取一个最高。
4. **NPC 名字**：默认就叫「钓具老板」。想起个名字（比如「老鲁」「鱼叔」）告诉我。
5. **升级奖励的币**：每级 `10 × 级数`（最多 200），累计到 30 级约 3000 币，偏小；觉得不够可以加。
6. **摊子的具体位置**：开工后我先出 2–3 个候选截图给你定。

## 10. 风险与注意
- **卖价加成是新的币产出**：上限死在 +20%，上线后看余额分布；要调只改常数。
- **配方门槛可能让新玩家觉得被卡**：好在门槛都不高（5 / 10 / 12 级），且老玩家按图鉴折算；文案要写清楚「还差几级」。
- **周委托的公平性**：全部自动计数、不用交鱼，没有"卡材料"的挫败；困难委托偏难但不惩罚。
- **摊子的地图位置**：属于地图改动，`npm run assets` 会重新生成地图；编译产物不入库，主人手动微调（地图编辑器）的内容不会被覆盖。
- **图标 / 美术量**：摊子 + NPC + 几个小图标，比 P2 小得多。
